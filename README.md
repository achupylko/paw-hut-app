## Installation

Clone the repository:

```bash
git clone https://github.com/achupylko/paw-hut-app.git
```

Go to the project folder:

```bash
cd paw-hut-app
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build project for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
